# News App

A React Native news application with Android and iOS project
structure, category selection, news API integration, and Redux
state management.

## Project status

This is a personal project originally developed in 2019.
It is being revisited for maintenance and documentation improvements.

The dependencies are older, and compatibility with current
development tools has not yet been verified.

## Features

- News category selection
- News API integration
- Navigation between app screens
- Redux-based state management
- Splash screen
